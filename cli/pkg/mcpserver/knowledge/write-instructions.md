## Write access

This server exposes incident actions plus dashboard, alerting, on-call, personal delivery and browser SDK configuration. Use mutating tools only for changes the user requested. Read `traceway://knowledge/operations` for permissions and routing to the focused configuration guides. Read current state, preserve unrelated settings, state the intended change, apply it, and verify the saved result. A 403 is a policy decision, not a reason to try another route. Channel/contact tests and SMS verification sends are real outbound messages; escalation tests open real pages.

Alert rules route to project channels. Escalation channels open pages governed by organization policies; targets resolve through teams and schedules to people, whose own contact methods and urgency chains determine delivery. Use `traceway://knowledge/alert-configuration`, `traceway://knowledge/oncall-configuration` and `traceway://knowledge/personal-notifications` before configuring these relationships. Organization administration requires owner/admin; personal settings belong only to the authenticated user. Project context supplies opt-in and auditing for these writes.

For dashboards use `traceway://knowledge/dashboard-building`; for browser collection use `traceway://knowledge/sdk-configuration`. Updates to shared dashboards affect all assigned projects. OpAMP edits require expected_updated_at, complete settings and saved-config preview; preserve unrelated rules and masking.
