| Symptom                                                                                        | Cause                                                                                                                                                                                                  | Fix                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The console shows `Traceway: init() failed and the SDK is off` with `init() needs a token`     | The build has no token: its environment variable is not set                                                                                                                                            | Set the variable (`VITE_TRACEWAY_TOKEN`, or your framework's public prefix) for that build and build again                                                               |
| An issue has no replay                                                                         | The error came within 5 seconds of the last clip, the session already had 20 clips, replay is off (`sessionRecording: false` or a rule), or the session's budget is used up                            | Read the reason on the error's event. To investigate a flow, stream replay with a rule for a while ([Step 4](#record-every-session-or-a-sample))                         |
| Masked text shows in clear                                                                     | The class is misspelled, it was added after recording started, or a stylesheet sets the picture                                                                                                        | Put the class in the markup from the start; use `traceway-blank` for pictures set by CSS                                                                                 |
| Pictures are empty boxes                                                                       | `replay.images` is `"off"`, or the pictures are inside a mask                                                                                                                                          | Check **Replay images** in the rules and `replay.images` in `collection`                                                                                                 |
| Pictures are broken in the replay                                                              | Their URL needs a login or has expired                                                                                                                                                                 | Set `replay.images` to `"always"`, which copies same-origin and CORS pictures                                                                                            |
| A trigger never fires                                                                          | The rule has not reached the tab yet, its conditions do not match this browser, the selector uses a form that is not supported, or the Navigation pattern differs in case or in the number of segments | Call `refreshConfig()` or wait for the next poll, check the browser with **Preview**, and check that `document.querySelector` finds the element with the step's selector |
| A capture never starts                                                                         | The target does not match what the browser reports, or the browser has not polled since                                                                                                                | Compare the value with the session's `service.instance.id` or `user.id`; call `refreshConfig()` after sign-in                                                            |
| Rules have no effect and `debug` logs `this server has no remote config; local settings apply` | The self-hosted Traceway server is older than remote config                                                                                                                                            | Upgrade the server; until then, `collection` sets the policy                                                                                                             |
| `403` on `/api/otel/v1/opamp`                                                                  | The token belongs to a backend or React Native project                                                                                                                                                 | Use the token of the browser project                                                                                                                                     |
| `401` on `/api/otel/v1/opamp`                                                                  | The token was rejected                                                                                                                                                                                 | Copy the token again from the project's **Connection** page                                                                                                              |
