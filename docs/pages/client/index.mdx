# Traceway

Traceway is an open-source error tracking and monitoring platform. It gives you real-time visibility into your application's health through exception tracking, endpoint monitoring, background tasks, and system metrics.

There are two ways to send data to it: backends of any language report over [OpenTelemetry](/client/otel), and browser or mobile apps use the Traceway SDKs.

> **First time here?** Read [Project Structure](/learn/projects) first: one project per backend system, per browser app, and per mobile app.
