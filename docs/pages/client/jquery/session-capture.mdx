# Configure Session Capture

<Intro />

This page uses `@tracewayapp/jquery`, from npm or its CDN build. [Session Replay](/client/js-sdk/session-replay) is the reference.

## Step 1: Turn on replay and set the limits in the app

<Step1>

```javascript
import $ from "jquery";
import { init } from "@tracewayapp/jquery";

init({
  token: import.meta.env.VITE_TRACEWAY_TOKEN,
  jQuery: $,
  version: "1.4.2",
  sessionRecording: true, // the default; false means no replay, whatever a rule says
  collection: {
    replay: { maskAllInputs: true, images: "wifi" },
  },
});
```

With the CDN build, the same object goes to `TracewayJQuery.init({ token: "YOUR_TOKEN", … })`, and the global jQuery is found without the `jQuery` option.

</Step1>

### Record a journey with a trigger

<Trigger>

```javascript
import { log, captureMessage } from "@tracewayapp/jquery";

$("#checkout").on("submit", async function (event) {
  event.preventDefault();
  const result = await submitPayment($(this).serialize());
  if (result.declined) {
    log("Payment declined", "warn", { provider: "stripe" }); // matches a Log step "Payment declined"
  }
  if (result.abandoned) {
    captureMessage("Checkout abandoned"); // also opens an issue
  }
});
```

On the CDN build these are `TracewayJQuery.log` and `TracewayJQuery.captureMessage`.

</Trigger>

### Name your pages

<Pages>

A page that is a URL of its own needs nothing more. Name the page by its template where the path holds ids, and report navigation the address does not show (a tab panel, a modal, a step of a wizard), whose path is what a **Navigation** step matches:

```javascript
import { setRoute, recordNavigation } from "@tracewayapp/jquery";

setRoute("/orders/:id");

$("#wizard").on("step", function (event, from, to) {
  recordNavigation(
    `/checkout/${to}`,
    "push",
    `/checkout/${from}`,
    "/checkout/:step",
  );
});
```

Without a route template, id-like path segments are replaced (`/orders/8841` becomes `/orders/:id`).

</Pages>

## Step 5: Capture one user or device from the dashboard

<Step5>

```javascript
import {
  setAttribute,
  refreshConfig,
  getInstanceId,
} from "@tracewayapp/jquery";

$(document).on("signed-in", async function (event, user) {
  setAttribute("user.id", String(user.id));
  await refreshConfig();
});

$("#device-id").text(getInstanceId() ?? "");
```

</Step5>
