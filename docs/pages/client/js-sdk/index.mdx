This reference covers the 2.x browser SDK and its framework wrappers. It uses OpenTelemetry and supports [remote collection settings](/learn/remote-config). See [Initialization](/client/js-sdk/initialization) and [Distributed Tracing](/client/js-sdk/distributed-tracing) when migrating from 1.x.

The Traceway JavaScript SDK provides error tracking for browser-based applications. It captures exceptions, messages, and sends them to your Traceway backend.

## Packages

| Package | Description |
|---------|-------------|
| `@tracewayapp/frontend` | Core browser SDK (framework-agnostic) |
| `@tracewayapp/react` | React bindings with Provider, Error Boundary, and hooks |
| `@tracewayapp/vue` | Vue 3 plugin and composables |
| `@tracewayapp/svelte` | Svelte context-based integration |
| `@tracewayapp/jquery` | jQuery integration with automatic AJAX error capture |

## Installation

```bash
npm install @tracewayapp/frontend@beta
```

Or use a framework-specific package:

```bash
npm install @tracewayapp/react@beta
npm install @tracewayapp/vue@beta
npm install @tracewayapp/svelte@beta
npm install @tracewayapp/jquery@beta
```

### Via CDN

The frontend and jQuery packages are also available as standalone scripts (no bundler required):

```html
<!-- Framework-agnostic (exposes window.Traceway) -->
<script src="https://cdn.jsdelivr.net/npm/@tracewayapp/frontend@beta/dist/traceway.iife.global.js"></script>
<script>
  Traceway.init("your-token@https://traceway.example.com/api/report");
</script>
```

```html
<!-- jQuery (exposes window.TracewayJQuery) -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@tracewayapp/jquery@beta/dist/traceway-jquery.iife.global.js"></script>
<script>
  TracewayJQuery.init("your-token@https://traceway.example.com/api/report");
</script>
```

## Connection String Format

All Traceway SDKs use a connection string to identify your project and endpoint:

```
<project_token>@<server_url>/api/report
```

Example:
```
abc123def456@https://traceway.example.com/api/report
```

You can find your connection string in the Traceway dashboard under **Project Settings**.

## When to Use

Use the generic `@tracewayapp/frontend` package when:

- You're using a framework without official bindings
- You need direct control over initialization
- You're building a vanilla JavaScript application
- You want to integrate with a custom framework

For React, Vue, or Svelte applications, use the framework-specific packages for better integration and developer experience.

## Basic Usage

```javascript
import { init, captureException, captureMessage } from "@tracewayapp/frontend";

// Initialize once at app startup
init("your-token@https://traceway.example.com/api/report");

// Capture errors
try {
  riskyOperation();
} catch (error) {
  captureException(error);
}

// Capture custom messages
captureMessage("User completed checkout");
```

## Features

- **Automatic batching**: Logs and spans go out in OTLP batches, by default about a second apart (`exportDelayMs`)
- **Automatic retry**: Batches that fail with a retryable status (such as 429 or 503) are retried with backoff; with `buffer.persist` they also survive page loads (see [Flush & Lifecycle](/client/js-sdk/flush))
- **Stack trace capture**: Full stack traces are captured for exceptions
- **Custom attributes**: Attach metadata to exceptions for better debugging
- **Distributed tracing**: Records `fetch` and `XMLHttpRequest` calls as spans and sends the W3C `traceparent` header, so a browser request and the backend work it caused share one trace. This covers `$.ajax()` and browser Axios with no extra setup (see [Distributed Tracing](/client/js-sdk/distributed-tracing))
- **Lightweight**: Minimal bundle size impact
