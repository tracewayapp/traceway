# Configure Session Capture

<Intro />

This page uses `@tracewayapp/frontend` directly. For a framework, follow its own page: [React](/client/react/session-capture), [Vue](/client/vue/session-capture), [Svelte](/client/svelte/session-capture) or [jQuery](/client/jquery/session-capture). [Session Replay](/client/js-sdk/session-replay) is the reference.

## Step 1: Turn on replay and set the limits in the app

<Step1>

```javascript
import { init } from "@tracewayapp/frontend";

init({
  token: import.meta.env.VITE_TRACEWAY_TOKEN,
  version: "1.4.2",
  sessionRecording: true, // the default; false means no replay, whatever a rule says
  replayImages: "always", // the default; "wifi" or "off" caps what a rule may allow for pictures
  collection: {
    // maskAllInputs: true here is a floor: no rule can unmask inputs
    replay: { maskAllInputs: true, images: "wifi" },
  },
});
```

With the CDN script, the same object goes to `Traceway.init({ token: "YOUR_TOKEN", … })`.

</Step1>

```html
  <img src="/avatars/42.jpg" alt="" /> Alice Smith

```

An element your script creates gets the class when it is created, before it is added to the page:

```javascript
const name = document.createElement("span");
name.className = "traceway-mask";
name.textContent = user.name;
document.querySelector("#account").append(name);
```

### Name your pages

<Pages>

The SDK reads the route template from React Router in framework mode, Remix, TanStack Router, the Next.js Pages Router, Vue Router and Nuxt without any code. For another router, hand it over once, or name the page yourself:

```javascript
import { trackRouter, setRoute, recordNavigation } from "@tracewayapp/frontend";

trackRouter(router); // a React Router data router, a TanStack Router, a Vue Router or the Next.js Pages Router

setRoute("/orders/:id"); // or name the page being shown; null goes back to the router's name

// Navigation the address does not show (a hash or memory router, a modal, a wizard step):
recordNavigation(
  "/checkout/payment",
  "push",
  "/checkout/address",
  "/checkout/:step",
);
```

A `recordNavigation` path is what a **Navigation** step matches, and it counts as a page view for the performance metrics. Without a route template, id-like path segments are replaced (`/orders/8841` becomes `/orders/:id`). See [Screens and navigation](/client/js-sdk#screens-and-navigation).

</Pages>

## Step 5: Capture one user or device from the dashboard

<Step5>

```javascript
import {
  setAttribute,
  refreshConfig,
  getInstanceId,
} from "@tracewayapp/frontend";

async function onSignedIn(user) {
  setAttribute("user.id", String(user.id));
  await refreshConfig();
}

document.querySelector("#device-id").textContent = getInstanceId() ?? "";
```

</Step5>
