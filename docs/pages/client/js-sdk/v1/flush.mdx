Understanding the SDK's batching behavior and how to control it.

## Batching Behavior

The Traceway SDK batches events to reduce network overhead:

1. Events are collected in memory
2. After `debounceMs` (default: 1500ms) of no new events, the batch is sent
3. If an upload fails, it retries after `retryDelayMs` (default: 10000ms)

This means events are not sent immediately. For most applications, this is the desired behavior.

## flush()

Use `flush()` when the page is finished recording, for example immediately before an application-controlled redirect or at the end of a test. In 1.x it stops the replay recorder, removes session lifecycle listeners, closes an always-on session, and attempts to send the pending batch. Let the normal batch timer handle errors when the user will keep interacting with the page.

```javascript
import { captureMessage, flush } from "@tracewayapp/frontend";

async function handleLogout() {
  captureMessage("User logged out");
  await flush(2000);
  window.location.href = "/login";
}
```

The optional timeout bounds the caller’s wait. An upload can fail and be queued for retry, or another upload may already be running. To verify delivery in a test, check the received report.

## Lifecycle Considerations

### Single Page Applications (SPAs)

For SPAs, initialize once at app startup. The SDK handles batching across route changes automatically.

```javascript
// main.js or index.js
import { init } from "@tracewayapp/frontend";

init("your-token@https://cloud.tracewayapp.com/api/report");
```

### Server-Side Rendering (SSR)

The SDK is browser-only. For SSR frameworks:

```javascript
// Only initialize on client
if (typeof window !== "undefined") {
  init("your-token@https://cloud.tracewayapp.com/api/report");
}
```

Or use framework-specific packages that handle this automatically.

## Tuning Batching

Adjust timing based on your needs:

```javascript
init("your-token@https://cloud.tracewayapp.com/api/report", {
  // Faster batching for critical apps
  debounceMs: 500,
  retryDelayMs: 5000,
});
```

```javascript
init("your-token@https://cloud.tracewayapp.com/api/report", {
  // More aggressive batching for high-traffic apps
  debounceMs: 3000,
  retryDelayMs: 15000,
});
```
