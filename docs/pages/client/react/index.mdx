# React Quick Start

Integrate Traceway into your React application with the `@tracewayapp/react` package.

Upgrading from 1.x? See the [migration guide](/client/js-sdk/migration).

## Installation

```bash
npm install @tracewayapp/react
```

## Setup

Wrap your application with `TracewayProvider`. It also acts as an error boundary: render-time exceptions thrown anywhere in the tree are captured and reported automatically, then re-thrown so your app behaves exactly as it would without Traceway installed. Session replay is on by default and stays on the device until it is needed: an error uploads a 30-second replay clip and up to 10 minutes of breadcrumbs (console output, requests, navigation, clicks). Set `recordAllSessions: true` to stream whole sessions instead:

```jsx
import { TracewayProvider } from "@tracewayapp/react";

function App() {
  return (
    <TracewayProvider connectionString="your-token@https://traceway.example.com/api/report">
      <YourApp />
    </TracewayProvider>
  );
}

export default App;
```

> **Custom fallback UI?** If you want to replace a crashed subtree with a fallback view instead of letting the error propagate, wrap the relevant section in `TracewayErrorBoundary`. It's still exported for that purpose, but is no longer required for capture.

React StrictMode double-invokes the provider's constructor in development. That is harmless: the second `init()` is a no-op, so there is still one SDK client. See [A note on StrictMode](/client/react/provider#a-note-on-strictmode).

## Capture Errors Manually

Use the `useTraceway` hook in components:

```jsx
import { useTraceway } from "@tracewayapp/react";

function MyComponent() {
  const { captureException } = useTraceway();

  async function handleSubmit() {
    try {
      await submitForm();
    } catch (error) {
      captureException(error);
    }
  }

  return <button onClick={handleSubmit}>Submit</button>;
}
```

## With Options

```jsx
<TracewayProvider
  connectionString="your-token@https://traceway.example.com/api/report"
  options={{
    debug: true,
    version: "1.0.0",
  }}
>
  <YourApp />
</TracewayProvider>
```

## Test Your Integration

```jsx
import { useTraceway } from "@tracewayapp/react";

function TestButton() {
  const { captureException } = useTraceway();

  return (
    <button onClick={() => captureException(new Error("Test error"))}>
      Send Test Error
    </button>
  );
}
```

Click the button and check your Traceway dashboard to verify the error appears.

## Distributed Tracing

The SDK records `fetch` and `XMLHttpRequest` calls as OpenTelemetry CLIENT spans and sends the W3C `traceparent` header on same-origin requests, which a backend instrumented with OpenTelemetry picks up with no extra middleware. The browser request and the backend work it caused then show up in one trace. For an API on another origin, list it in the `propagateTraceHeaderCorsUrls` option. See [Distributed Tracing](/client/js-sdk/distributed-tracing).
