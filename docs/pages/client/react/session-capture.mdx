## Step 1: Turn on replay and set the limits in the app

<Step1>

```jsx
import { TracewayProvider } from "@tracewayapp/react";

export function App() {
  return (
    <TracewayProvider
      token={import.meta.env.VITE_TRACEWAY_TOKEN}
      options={{
        version: "1.4.2",
        sessionRecording: true, // the default; false means no replay, whatever a rule says
        collection: {
          replay: { maskAllInputs: true, images: "wifi" },
        },
      }}
    >
      <YourApp />
    </TracewayProvider>
  );
}
```

Next.js reads the token from `process.env.NEXT_PUBLIC_TRACEWAY_TOKEN`. The provider reads its props once, when it mounts.

</Step1>

In JSX the attribute is `className`:

```jsx
function AccountCard({ user, card }) {
  return (
    <section>
      <p className="traceway-mask">
        Card ending {card.last4}, {user.name}
      </p>
      <div className="traceway-mask">
        <img src={user.avatarUrl} alt="" /> {user.name}
      </div>
      <div className="traceway-blank">
        <SignaturePad />
      </div>
    </section>
  );
}
```

`Card ending 4242, Alice Smith` replays as `**** ****** ***** ***** *****`. Render the class with the element, not from an effect after it mounted.

</Mask>

### Record a journey with a trigger

<Trigger>

```jsx
import { log, captureMessage } from "@tracewayapp/react";

async function pay(order) {
  const result = await submitPayment(order);
  if (result.declined) {
    log("Payment declined", "warn", { provider: "stripe" }); // matches a Log step "Payment declined"
  }
  if (result.abandoned) {
    captureMessage("Checkout abandoned"); // also opens an issue
  }
}
```

</Trigger>

### Name your pages

<Pages>

React Router in framework mode, Remix, TanStack Router and the Next.js Pages Router need no code. A React Router data router goes to the provider; with `<BrowserRouter>` and `<Routes>`, or the Next.js App Router, call `useTracewayRoute` with the path and its params:

```jsx
import { createBrowserRouter, RouterProvider } from "react-router-dom";
import { TracewayProvider } from "@tracewayapp/react";

const router = createBrowserRouter(routes);

<TracewayProvider token={import.meta.env.VITE_TRACEWAY_TOKEN} router={router}>
  <RouterProvider router={router} />
</TracewayProvider>;
```

```jsx
// React Router with <Routes>: a layout route sees the params of the page below it
import { Outlet, useLocation, useParams } from "react-router-dom";
import { useTracewayRoute } from "@tracewayapp/react";

function Layout() {
  useTracewayRoute(useLocation().pathname, useParams());
  return <Outlet />;
}
```

For navigation the address does not show (a modal, a wizard step, a memory router), report it. Its path is what a **Navigation** step matches:

```jsx
import { recordNavigation } from "@tracewayapp/react";

recordNavigation(
  "/checkout/payment",
  "push",
  "/checkout/address",
  "/checkout/:step",
);
```

[Route Names](/client/react/hooks#usetracewayroute) has the Next.js App Router component and the other forms.

</Pages>

## Step 5: Capture one user or device from the dashboard

<Step5>

```jsx
import { useEffect } from "react";
import { useTracewayAttributes, refreshConfig } from "@tracewayapp/react";

function SignedInShell({ user, children }) {
  useTracewayAttributes(user ? { "user.id": String(user.id) } : null);
  useEffect(() => {
    if (user) refreshConfig();
  }, [user?.id]);
  return children;
}
```

</Step5>
