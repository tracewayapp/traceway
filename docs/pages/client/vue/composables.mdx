# Composables

Use the `useTraceway` composable to capture errors and messages in Vue components.

## useTraceway

```vue
<script setup>
import { useTraceway } from "@tracewayapp/vue";

const { captureException, captureExceptionWithAttributes, captureMessage, recordAction } = useTraceway();
</script>
```

## Return Value

| Function | Description |
|----------|-------------|
| `captureException(error, attributes?)` | Capture an error with stack trace |
| `captureExceptionWithAttributes(error, attributes)` | Capture an error with metadata. Attribute values are strings |
| `captureMessage(message, attributes?)` | Send a custom message, listed on the Issues page |
| `recordAction(category, name, data?)` | Add a custom entry to the session timeline |

These four are the whole return value. Everything else is imported from `@tracewayapp/vue` directly, see [Direct Imports](#direct-imports).

## captureException

Capture errors in event handlers or async functions:

```vue
<script setup>
import { useTraceway } from "@tracewayapp/vue";

const { captureException } = useTraceway();

async function handleSubmit() {
  try {
    await submitForm();
  } catch (error) {
    captureException(error);
    showErrorNotification("Submission failed");
  }
}
</script>

<template>
  <button @click="handleSubmit">Submit</button>
</template>
```

## captureExceptionWithAttributes

Add context to errors:

```vue
<script setup>
import { useTraceway } from "@tracewayapp/vue";

const props = defineProps(['userId']);
const { captureExceptionWithAttributes } = useTraceway();

async function loadData() {
  try {
    const data = await fetchUserData(props.userId);
    // ...
  } catch (error) {
    captureExceptionWithAttributes(error, {
      userId: String(props.userId),
      action: "loadUserData",
    });
  }
}
</script>
```

## captureMessage

Report an event that is not an error. A message is listed on the Issues page; for an event that should only show on the session timeline, use `recordAction` or `track`:

```vue
<script setup>
import { useRouter } from "vue-router";
import { useTraceway } from "@tracewayapp/vue";

const router = useRouter();
const { captureMessage } = useTraceway();

function handleCheckout() {
  captureMessage("User started checkout");
  router.push("/checkout");
}
</script>

<template>
  <button @click="handleCheckout">Proceed to Checkout</button>
</template>
```

## recordAction

Drop a breadcrumb into the session timeline. It does not create an issue on its own. Like the automatic console, network, navigation and click entries it stays on the device by default and is uploaded with the next error of the session (up to the last 10 minutes), or continuously with `recordAllSessions: true`:

```vue
<script setup>
import { useTraceway } from "@tracewayapp/vue";

const { recordAction } = useTraceway();

function startCheckout() {
  recordAction("checkout", "started", { cartSize: 3 });
}
</script>

<template>
  <button @click="startCheckout">Start Checkout</button>
</template>
```

## useTracewayAttributes

`useTracewayAttributes(mapOrGetter)` binds reactive state to the global attribute scope, so every session and exception carries it, and removes its keys when the component unmounts. `<TracewayAttributes :attributes="..." />` is the same thing as a component:

```vue
<script setup>
import { useTracewayAttributes } from "@tracewayapp/vue";

const props = defineProps(['userId']);
useTracewayAttributes(() => ({ "user.id": String(props.userId) }));
</script>
```

See [Custom Attributes](/client/vue/plugin#custom-attributes) for the details.

## Direct Imports

`@tracewayapp/vue` re-exports the browser SDK's functions, so they can be imported anywhere, outside components too:

```javascript
import { track, metric, count, flush } from "@tracewayapp/vue";

track("checkout_failed", { step: "payment" }); // a named event on the session timeline
metric("checkout.duration", 840, { plan: "pro" }); // one observation of a custom distribution
count("cart.item_added"); // a custom counter

await flush(); // send everything that is queued for sending
```

| Function | Description |
|----------|-------------|
| `captureException`, `captureExceptionWithAttributes`, `captureMessage`, `recordAction` | The same functions `useTraceway()` returns |
| `log(message, level?, attributes?)` | Record a log line of your own, handled like a `console.*` line (releases after 2.0.3). See [Logs](/client/js-sdk#logs) |
| `track(eventName, attributes?)` | Record a named app event. [Triggers](/learn/remote-config) can match it |
| `metric(name, value, dims?)`, `count(name, n?, dims?)` | Custom [performance metrics](/learn/client-metrics), aggregated on the device |
| `setMetricDimension(key, value)` | Put a dimension of your own on every performance metric; `null` removes it |
| `setRoute(template)` | Name the current page by its route template. [`trackRouter`](/client/vue/plugin#route-names) calls it for you |
| `startInteraction(name)` | Trace a multi-step interaction, see [Distributed Tracing](/client/js-sdk/distributed-tracing#trace-an-entire-interaction-explicitly) |
| `setAttribute`, `setAttributes`, `removeAttribute`, `clearAttributes` | The global attribute scope, see [Custom Attributes](/client/vue/plugin#custom-attributes) |
| `refreshConfig()` | Fetch the remote collection settings now instead of at the next poll |
| `flush(timeoutMs?)`, `shutdown()` | See [Flush & Lifecycle](/client/js-sdk/flush) |
| `getInstanceId()` | The id this browser profile reports as `service.instance.id` |
| `currentSessionId()` | The current session's id (`session.id`), or `null` before the plugin is installed and between sessions (releases after 2.0.3) |

## Composable Pattern

Create reusable async handlers:

```javascript
// composables/useTrackedFetch.js
import { ref } from "vue";
import { useTraceway } from "@tracewayapp/vue";

export function useTrackedFetch(url, context = {}) {
  const { captureExceptionWithAttributes } = useTraceway();
  const data = ref(null);
  const error = ref(null);
  const loading = ref(false);

  async function execute() {
    loading.value = true;
    error.value = null;
    try {
      const response = await fetch(url);
      data.value = await response.json();
    } catch (err) {
      error.value = err;
      captureExceptionWithAttributes(err, {
        url,
        ...context,
      });
    } finally {
      loading.value = false;
    }
  }

  return { data, error, loading, execute };
}
```

Usage:

```vue
<script setup>
import { onMounted } from "vue";
import { useTrackedFetch } from "@/composables/useTrackedFetch";

const { data, error, loading, execute } = useTrackedFetch(
  "/api/users",
  { component: "UserList" }
);

onMounted(execute);
</script>
```

## Options API

For Options API components, use `inject`:

```vue
<script>
import { TracewayKey } from "@tracewayapp/vue";

export default {
  inject: {
    traceway: { from: TracewayKey },
  },
  methods: {
    handleError(error) {
      this.traceway.captureException(error);
    },
  },
};
</script>
```

## Error Handling Best Practices

```vue
<script setup>
import { useTraceway } from "@tracewayapp/vue";
import { ref } from "vue";

const { captureException } = useTraceway();
const errorMessage = ref("");

async function handleAction() {
  errorMessage.value = "";
  try {
    await performAction();
  } catch (error) {
    // 1. Capture for monitoring
    captureException(error);

    // 2. Show user-friendly message
    errorMessage.value = "Action failed. Please try again.";

    // 3. Optionally rethrow for error boundaries
    // throw error;
  }
}
</script>

<template>
  <div>
    <button @click="handleAction">Perform Action</button>
    <p v-if="errorMessage" class="error">{{ errorMessage }}</p>
  </div>
</template>
```
