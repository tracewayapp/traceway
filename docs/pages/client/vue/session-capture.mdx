# Configure Session Capture

<Intro />

This page uses `@tracewayapp/vue`. [Session Replay](/client/js-sdk/session-replay) is the reference.

## Step 1: Turn on replay and set the limits in the app

<Step1>

```javascript
import { createApp } from "vue";
import { createTracewayPlugin } from "@tracewayapp/vue";
import App from "./App.vue";
import { router } from "./router";

const app = createApp(App);

app.use(router);
app.use(
  createTracewayPlugin({
    token: import.meta.env.VITE_TRACEWAY_TOKEN,
    options: {
      version: "1.4.2",
      sessionRecording: true, // the default; false means no replay, whatever a rule says
      collection: {
        replay: { maskAllInputs: true, images: "wifi" },
      },
    },
  }),
);

app.mount("#app");
```

In Nuxt, the same `token` and `options` go to the plugin in `plugins/traceway.ts` (see [Nuxt Integration](/client/vue/plugin#nuxt-integration)).

</Step1>

`Card ending 4242, Alice Smith` replays as `**** ****** ***** ***** *****`. Put the class in the template itself; a class bound later with `:class` leaves the element unmasked until the next full snapshot.

### Record a journey with a trigger

<Trigger>

```javascript
import { log, captureMessage } from "@tracewayapp/vue";

export async function pay(order) {
  const result = await submitPayment(order);
  if (result.declined) {
    log("Payment declined", "warn", { provider: "stripe" }); // matches a Log step "Payment declined"
  }
  if (result.abandoned) {
    captureMessage("Checkout abandoned"); // also opens an issue
  }
}
```

</Trigger>

### Name your pages

<Pages>

With Vue Router or Nuxt there is nothing to add: the plugin reads the router installed in the same app and names each page by its matched route, such as `/orders/:id` (Nuxt file routes end in `()`, `/orders/:id()`). A router the app does not install is passed once with `trackRouter(router)`.

For navigation the address does not show (a modal, a wizard step, a memory history), report it. Its path is what a **Navigation** step matches:

```javascript
import { recordNavigation } from "@tracewayapp/vue";

recordNavigation(
  "/checkout/payment",
  "push",
  "/checkout/address",
  "/checkout/:step",
);
```

See [Route Names](/client/vue/plugin#route-names).

</Pages>

## Step 5: Capture one user or device from the dashboard

<Step5>

```vue
<script setup>
import { watch } from "vue";
import { useTracewayAttributes, refreshConfig } from "@tracewayapp/vue";
import { useUser } from "./auth";

const { user } = useUser();

useTracewayAttributes(() =>
  user.value ? { "user.id": String(user.value.id) } : null,
);
watch(
  () => user.value?.id,
  (id) => {
    if (id) refreshConfig();
  },
  { immediate: true },
);
</script>
```

</Step5>
